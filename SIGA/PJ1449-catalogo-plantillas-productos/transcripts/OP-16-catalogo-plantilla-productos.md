# OP-16: Implementar catálogo de plantilla de productos

## Problema
Cada producto requiere una plantilla de contrato independiente, actualmente la plantilla del
producto se carga y en ocasiones no se tiene a la mano el archivo dificultando la gestión
documental.

## Solución
Se requiere tener un módulo en donde se puedan subir las plantillas y al momento de configurar
un producto se pueda seleccionar alguno de este catálogo y si no se encuentra en ese listado
poder seleccionarlo a como se realiza actualmente.

Crear catálogo de plantillas reutilizables asociables a múltiples productos.
