# CA-05 : Permitir Acceso a distribuidores, productos y precios para el Rol Ejecutivo de Ventas

## Problema
El Ejecutivo de Ventas no tiene visibilidad sobre productos y precios cargados para sus clientes asignados.

## Solución
Ampliar los permisos del Ejecutivo de Ventas para incluir acceso de solo lectura a productos y precios de sus distribuidores asignados.
Solo permiso de lectura, no actualizar datos ni descargar reportes.

Esta funcionalidad dejarla preparada para todos los paises, sin embargo la habilitación o no de esta funcionalidad deberá quedar
en los settings, es decir que en los settings exista un parametro que indique si esta funcionalidad se permite o no.
